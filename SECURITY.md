# Security policy

## Supported versions

Security fixes are provided for the latest dpm v1 release. The supported
runtime and trust boundary are documented in [THREAT_MODEL.md](THREAT_MODEL.md).

## Private reporting

Do not open a public issue for a suspected vulnerability. Use GitHub's private
[security advisory form](https://github.com/kevherro/dpm/security/advisories/new)
and include the affected version, reproduction steps, impact, and any proposed
mitigation. If the form is unavailable, contact the repository owner through
the private contact method listed on their GitHub profile.

You should receive an acknowledgement within seven days. Please allow time for
investigation and a coordinated fix before public disclosure.
